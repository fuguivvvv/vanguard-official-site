Bash

git init

# 2. 将所有代码文件添加到暂存区
git add .

# 3. 提交代码并附带能证明开发者的提交日志（Commit Message）
git commit -m "Initial commit: Full-stack Nuxt 3 architecture & custom UI components for Vanguard"

# 4. 切换主分支名称为 main
git branch -M main

# 5. 关联您刚在 GitHub 创建的远程仓库（请替换为您自己的真实 GitHub 仓库 URL）
git remote add origin https://github.com/fuguvvvv/vanguard-official-site.git

# 6. 推送代码到 GitHub
git push -u origin main

以下是 PM2 的常用命令整理，按照日常开发和生产环境中的高频使用场景进行了分类：

1. 启动与管理应用
通过配置文件启动（推荐，适合生产环境）：

Bash
pm2 start ecosystem.config.js
启动并指定应用名称：

Bash
pm2 start app.js --name "my-app"
启动集群模式（利用多核 CPU 性能）：

Bash
pm2 start app.js -i max
查看运行中的应用列表：

Bash
pm2 list
# 或
pm2 status
查看应用详细信息：

Bash
pm2 show <app_name|id>
2. 停止、重启与删除
停止指定应用：

Bash
pm2 stop <app_name|id>
重启指定应用：

Bash
pm2 restart <app_name|id>
热重载（零停机重载，仅集群/合适架构支持）：

Bash
pm2 reload <app_name|id>
删除指定应用（从 PM2 列表中移除）：

Bash
pm2 delete <app_name|id>
停止/重启/删除所有应用：

Bash
pm2 stop all
pm2 restart all
pm2 delete all
3. 日志管理
实时查看所有应用的日志：

Bash
pm2 logs
查看指定应用的日志：

Bash
pm2 logs <app_name|id>
清空所有日志文件：

Bash
pm2 flush
4. 监控与诊断
实时监控 CPU / 内存占用（终端交互界面）：

Bash
pm2 monit
5. 开机自启与状态保存
保存当前运行的应用列表（用于恢复）：

Bash
pm2 save
生成并配置开机自启动脚本：

Bash
pm2 startup
(执行后终端通常会输出一行命令，复制并以 root 权限运行即可)
